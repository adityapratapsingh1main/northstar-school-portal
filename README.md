# Northstar Academy Portal

A school portal starter with a responsive interface, role-based accounts, a Node.js API, and SQLite storage.

## Features

- Separate administrator, teacher, student, and parent views
- Student, class, timetable, and attendance records
- School announcements and assignments
- Assessments, grades, fee plans, and invoices
- Role-based access checks and an audit trail
- SQLite database stored locally by default

## Requirements

- Node.js 24 or newer
